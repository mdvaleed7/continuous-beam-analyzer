# Chapter 8 — Comparisons at a Glance

Quick-revision tables for design reviews, site discussions and interviews.

## 8.1 One-Way Slab vs Two-Way Slab

| Aspect | One-Way | Two-Way |
|---|---|---|
| Ly/Lx | > 2 | ≤ 2 |
| Bending | Single curvature (short span) | Double curvature (both spans) |
| Main steel | One direction | Both directions |
| Corner/torsion steel | Not needed | Needed at discontinuous corners |
| Analysis | 1 m strip as beam | Annex D coefficients / plate theory |
| Economy | Small/corridor panels | Square-ish panels |

## 8.2 Flat Slab vs Conventional (Beam–Slab) System

| Aspect | Flat Slab | Beam–Slab |
|---|---|---|
| Beams | None (direct to columns) | Slab supported on beams |
| Storey height | Lower (no beam depth) | Higher |
| Formwork | Simple, fast | Complex |
| Services | Unobstructed soffit | Beams obstruct ducts |
| Critical check | Punching shear | Beam shear/flexure |
| Seismic behaviour | Poor as lateral system; needs shear walls in Zones III–V | Frames can be SMRF |
| Deflection | Larger | Smaller |

## 8.3 Flat Plate vs Flat Slab (with Drops) vs Waffle

| Aspect | Flat Plate | Flat Slab + Drops | Waffle |
|---|---|---|---|
| Span range | 4.5–6 m | 6–9 m | 9–15 m |
| Punching capacity | Lowest | Improved by drop | Solid heads at columns |
| Self-weight | Moderate | Moderate | Lowest per span |
| Formwork | Simplest | Simple | Pans/moulds needed |

## 8.4 Under-Reinforced vs Over-Reinforced Section

| Aspect | Under-Reinforced | Over-Reinforced |
|---|---|---|
| First to reach limit | Steel yields | Concrete crushes |
| Failure nature | Ductile, with warning | Brittle, sudden |
| xu vs xu,max | xu < xu,max | xu > xu,max |
| Code stance | Required | Prohibited |

## 8.5 Short Column vs Slender Column

| Aspect | Short | Slender |
|---|---|---|
| le/D | ≤ 12 | > 12 |
| Governing effect | Material strength | Buckling / P–Δ additional moments |
| Design | Direct P–M | Additional moment method (Cl. 39.7) |

## 8.6 OMRF vs SMRF

| Aspect | OMRF | SMRF |
|---|---|---|
| Detailing code | IS 456 only | IS 456 + IS 13920 |
| R factor | 3.0 | 5.0 |
| Design seismic force | Higher (÷3) | Lower (÷5) |
| Ductility | Ordinary | Special (confinement, capacity design) |
| Zones permitted | II only | All zones |

## 8.7 Shear Wall vs Moment Frame vs Braced Frame

| Aspect | Shear Wall | Moment Frame | Braced Frame |
|---|---|---|---|
| Load resistance | Wall bending/shear | Member flexure | Brace axial force |
| Deflected shape | Bending mode | Shear mode | Shear-ish (axial) |
| Stiffness | Very high | Low–moderate | High |
| Architectural freedom | Blocks openings | Maximum | Braces block bays |
| Typical material | RC | RC/steel | Steel |
| Best use | Cores, seismic drift control | Low–mid rise, flexible plans | Steel buildings, retrofit |

## 8.8 Retaining Wall vs Basement Wall

| Aspect | Cantilever Retaining Wall | Basement Wall |
|---|---|---|
| Support | Free cantilever from base | Propped top & bottom (slabs) |
| Earth pressure | Active (Ka) — wall can yield | At-rest (K0) — restrained |
| Governing moment | wH³ order at stem base | Much smaller (spanning) |
| Stability checks | Overturning, sliding, bearing | Usually not critical (tied into structure) |
| Section economy | Heavy stem/base | Thinner wall |

## 8.9 Isolated vs Combined vs Raft vs Pile

| Aspect | Isolated | Combined | Raft | Pile |
|---|---|---|---|---|
| Use case | Good soil, spaced columns | Close/boundary columns | Weak soil, footings > 50 % area, basements | Weak soil to depth, heavy loads |
| Cost | Lowest | Moderate | High | Highest |
| Settlement control | Per column | Shared | Best bridging | Bypasses weak strata |
| Key checks | Punching, one-way shear, flexure | Longitudinal beam action | Plate on elastic foundation, uplift | Capacity, group, downdrag, lateral |

## 8.10 End-Bearing Pile vs Friction Pile

| Aspect | End-Bearing | Friction |
|---|---|---|
| Load transfer | Tip on hard stratum | Shaft skin friction |
| Needs | Reachable rock/dense layer | Adequate shaft length in cohesive/granular soil |
| Group effect | Minor | Significant (overlap, block failure) |
| Settlement | Small | Depends on consolidation of surrounding soil |

## 8.11 Pre-Tensioning vs Post-Tensioning

| Aspect | Pre-Tensioning | Post-Tensioning |
|---|---|---|
| Sequence | Steel stressed before concrete cast | Stressed after concrete gains strength |
| Location | Factory (precast) | Site (in-situ) |
| Bond | Direct bond transfer | Anchorages + grouted/unbonded ducts |
| Profile | Straight/harped | Draped (parabolic) — efficient |
| Typical use | Hollow-core planks, poles, sleepers | Long-span slabs, transfer girders, bridges |

## 8.12 Working Stress vs Limit State Method

| Aspect | WSM | LSM |
|---|---|---|
| Basis | Elastic stresses ≤ permissible | Probabilistic limit states (collapse + serviceability) |
| Safety | Single FoS on stresses | Partial factors on loads AND materials |
| Material use | Conservative | Efficient (realistic stress blocks) |
| Status | Legacy (Annex B of IS 456) | Standard design method |

## 8.13 Determinate vs Indeterminate (recap)

| Aspect | Determinate | Indeterminate |
|---|---|---|
| Analysis | Statics sufficient | Compatibility + stiffness needed |
| Settlement/temperature | No induced forces | Induces forces |
| Robustness | No redundancy | Redistribution, robust |
| Example | Simply supported beam | Continuous beam, frames |

## 8.14 Steel vs Concrete (Buildings)

| Aspect | Structural Steel | Reinforced Concrete |
|---|---|---|
| Strength/weight | Excellent | Moderate |
| Speed | Fast erection, prefabricated | Slower (curing), formwork |
| Spans | Long spans easy | Moderate (PT extends) |
| Fire | Needs protection | Inherent cover protection |
| Maintenance | Corrosion protection | Low |
| Ductility | Naturally ductile | Detailing-dependent |
| Foundations | Lighter loads | Heavier |
